# ことばの方程式

思考や価値観を1枚の方程式画像にする、無料のツール。
「人生の成果 ＝ 能力 × 熱量 × 考え方」のような式も、「思い出 ＞ お金」のような比較も、X / note / Instagram / TikTok 向けの画像として書き出せます。

- すべての機能が無料。ログイン・回数制限・広告なし
- 収益は任意の寄付（Buy Me a Coffee など）のみ
- 画像生成も履歴保存もブラウザ内で完結（サーバーに送信しない）

## 機能

| | |
| --- | --- |
| サイズ | 16:9 1200×675（X）/ note 1280×670 / 1:1 1080 / 4:5 1080×1350 / 9:16 1080×1920（TikTok・リール） |
| 書き出し | 2倍解像度のPNG保存、クリップボードコピー（対応ブラウザのみ） |
| 共有 | 「画像を保存してXでシェア」でダウンロードとX投稿画面を同時に起動 |
| 履歴 | 直近5件を localStorage に保存し、ワンクリックで復元 |
| 関係記号 | 左側と右側をつなぐ `＝ ＞ ＜ ≧ ≦ ≠ ≒ →` をプルダウンから選択。1文字だけ直接入力もできる |
| 演算子 | `× ＋ − ÷ ＝ ⇒ ＞ ＜` をプルダウンから選択。「・・・」を選ぶと1文字だけ直接入力できる |
| レイアウト | 自動 / 横1行 / 上下の3選択。自動では「1 ＜ 2」のような短い式だけ横一列になる |
| 書体 | Sans（Inter + Noto Sans JP）/ Mono（JetBrains Mono + Noto Sans Mono） |
| 配色 | Paper / Mist / Ink の3パレット、ロゴ表示のON/OFF |
| クレジット | アカウント名と © 表記を画像右下に入れられる |
| 入力上限 | 結果24 / 要素18×最大8項 / 演算子1 / 補足56 / クレジット24文字（各欄にカウンタ表示） |
| テンプレート | 15種のプリセット |

### レイアウト崩れ対策

`src/lib/render.ts` が描画のすべてを担当します。文字数や要素数が増えても崩れないよう、次を実装しています。

- 見出し・補足は禁則処理つきの文字単位で折り返し
- 方程式は「演算子＋要素」を1グループとして行送りするため、行末に演算子が取り残されない
- 1要素が1行に収まらない場合のみ、その要素を文字単位で分割
- 全ブロックの合計高さが収まるまで基準サイズを段階的に縮小し、上下中央に再配置
- 縦長（1:1 / 4:5 / 9:16）では逆に拡大し、どの比率でも同じ光学的な重さに揃える
- 補足には最小サイズを設定し、縮小しても読めるサイズを維持
- 入力自体にも上限（`LIMITS`）を設け、破綻する入力をそもそも作れないようにしている

### ブラウザ対応

Chromium / Firefox / WebKit（Safari）の3エンジンで、375px～1680px の5画面幅と全サイズの描画を検証しています。

- `ctx.letterSpacing` はChromeのみのため、ロゴの字間は1文字ずつ描画して再現
- 日本語WebフォントはDOMに使われた文字だけが読み込まれるため、`document.fonts.load()` で必要な字形を明示的に取得してから描画
- `ClipboardItem` 非対応ブラウザ（Firefox等）ではコピーボタンを非表示
- iOS Safari のフォーカス時ズームを防ぐため、モバイルの入力欄は16px

## ブランド

ユーティリティ・ミニマリズムなマイクロSaaSのUIを下地に、道具としての清潔さを保ちながら柔らかさを加えています。

- **ロゴ**：角丸の正方形に、少しずらした2本のバー。「ちょっとずれた等号＝ことばで組む方程式」を表す。定義は `src/lib/logo.ts`（SVGとCanvasで共通）
- **色**：地はごく淡い青グレー（`#F1F4F9`）、面は白、アクセントはインクブルー（`#2B4EE6`）、破壊的な操作のみ赤
- **模様**：背景に24pxピッチのドットグリッドと淡いグラデーションを固定配置し、スクロールでコンテンツが浮き上がる
- **動き**：ヘッダーはスクロールで縮み、セクションは初回表示時にフェードイン（`prefers-reduced-motion` で無効化）
- **出力画像**：同じドットグリッドとロゴを入れ、関係記号と演算子をアクセント色で描画してサイトと見た目を揃えている

## セットアップ

```bash
npm install
cp .env.example .env.local   # 必要な値を設定
npm run dev
```

| 環境変数 | 用途 |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | 公開URL（OGP・sitemap・canonical に使用） |
| `NEXT_PUBLIC_DONATE_URL` | 寄付ページのURL。未設定なら寄付リンクは表示されません |
| `NEXT_PUBLIC_CONTACT_URL` | 問い合わせ先URL（任意） |

## デプロイと負荷

1. Vercel（または Cloudflare Pages）でこのリポジトリをインポート
2. 上記の環境変数を設定
3. デプロイ後、Google Search Console に `https://<ドメイン>/sitemap.xml` を送信

アクセスが伸びてもサーバー側の負荷はほとんど増えません。

- 全ページがビルド時に静的生成（`npm run build` の出力はすべて `○ Static`）され、CDNから配信される
- 画像生成は Canvas API でブラウザ内だけで実行。サーバーでのレンダリングは行わない
- 入力内容も履歴も送信しないので、APIルート・DB・セッションストアは一切なし
- フォントは `next/font` でビルド時に自己ホストされ、実行時に外部へ取りに行かない
- 将来サーバー側機能（OGP動的生成などを追加する場合）は、キャッシュとレート制限を別途入れること
